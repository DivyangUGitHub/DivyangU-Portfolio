## 🎯 About This Project

> A **responsive, performance-obsessed personal portfolio** engineered to feel less like a static webpage and more like an *experience*. Real-time WebGL scenes, physics-driven scroll animations, and cinematic transitions — shipped at **sub-2-second load times**.

## 🏗️ Architecture

```mermaid
flowchart LR
    A(["👤 Visitor"]) --> B["🌐 Vercel Edge Network"]
    B --> C["⚛️ Next.js App Router"]
    C --> D["🧱 Static / Server Components"]
    C --> E["🎮 Three.js Canvas Layer"]
    E --> F["🖥️ WebGL Renderer"]
    C --> G["🎬 GSAP + Framer Motion Layer"]
    G --> H["📜 Scroll-Synced Animations"]
    D --> I["📦 Optimized Assets + CDN Cache"]
    I --> J(["⚡ Sub-2s First Paint"])

    style A fill:#ec4899,stroke:#fff,color:#fff
    style J fill:#6366f1,stroke:#fff,color:#fff
    style F fill:#302b63,stroke:#fff,color:#fff
```

### 🔄 Render Lifecycle

```mermaid
sequenceDiagram
    participant U as 👤 User
    participant V as 🌐 Vercel Edge
    participant N as ⚛️ Next.js
    participant T as 🎮 Three.js Canvas
    participant G as 🎬 GSAP/Framer

    U->>V: Request page
    V->>N: Route to App Router
    N->>N: Stream Server Components
    N->>T: Mount WebGL Canvas
    T-->>U: Render 3D Scene (async)
    U->>G: Scroll event
    G->>N: Trigger animation timeline
    N-->>U: Buttery-smooth transition ✨
```

## 🚀 Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/DivyangUGitHub/DivyangU-Portfolio.git
cd DivyangU-Portfolio

# 2. Install dependencies
npm install

# 3. Run the dev server
npm run dev
```

Open **[localhost:3000](http://localhost:3000)** to view it locally. 🎉

<details>
<summary>📦 <b>Build for production</b></summary>

```bash
npm run build
npm run start
```
</details>
